# 口播稿 · 注册功能

> 事实依据（均已核对代码，可放心念）：
> 前端表单四项校验＝用户名 `3–32 位字母/数字/下划线`、密码 `≥8 位且同时含字母和数字`、两次密码一致、必须勾选「平台账号与数据安全规范」；
> 后端 `POST /api/auth/register` 用户名正则复核、重复用户名拦截、`role` 强制 `VIEWER`（自助注册一律只读成员）、密码哈希存储、
> 并写入审计 `REGISTER / 自助注册成功，默认角色 VIEWER`（含来源 IP）；注册成功不直接发 token，而是回到登录页并预填用户名，需再登录一次进工作台。

---

## 零、极简版（约 19 秒 · 82 字 · 4.3 字/秒）

登录页点「立即注册」。用户名三到三十二位，密码至少八位、必须含字母和数字，两次一致并同意安全规范；提交后密码哈希存储、写入注册审计，而且**自助注册一律是只读成员**，要提权必须由管理员改角色。

---

## 一、主推版（约 50 秒 · 213 字 · 4.3 字/秒）

平台支持自助注册。登录页点「立即注册」即可切换。

表单有四道校验：用户名 3 到 32 位字母、数字或下划线；密码至少 8 位并且必须同时含字母和数字；两次输入必须一致；还要勾选平台账号与数据安全规范。

提交后，后端会复核用户名、拦截重复账号，密码哈希存储，并写入一条注册审计，记录来源 IP。

这里有一个安全设计：**自助注册的账号一律是只读成员**，只能查看，不能创建和提交作业；要提权必须由管理员在用户管理里调整角色——这符合最小权限原则。

注册成功后回到登录页，用户名已自动填好，登录即可进入工作台。

## 二、精简版（约 27 秒 · 116 字 · 4.3 字/秒）

注册入口在登录页，点「立即注册」。

用户名 3 到 32 位，密码至少 8 位且要含字母和数字，两次一致，并同意安全规范。

提交后后端复核账号、密码哈希存储、写入注册审计，并且**自助注册一律是只读成员**，要提权只能由管理员改角色。

注册成功后回到登录页，用户名已填好，登录即进入工作台。

## 三、详版（约 66 秒 · 285 字 · 4.3 字/秒）

介绍注册功能。登录页点「立即注册」，就切换到注册表单。

第一，用户名：3 到 32 位，只能用字母、数字或下划线；

第二，密码：至少 8 位，而且必须同时包含字母和数字，两次输入要保持一致；

第三，必须勾选「平台账号与数据安全规范」才能提交。任一项不满足，错误提示会直接显示在表单里。

提交后，后端会再做一次用户名格式复核、拦截重复账号，密码用哈希存储不可逆；同时写入一条注册审计，记录账号、动作和来源 IP，便于追溯。

最关键的是一点安全设计：**自助注册的账号角色固定为只读成员**，只能查看作业和监控，不能创建、提交或修改任何资源；需要写权限，必须由管理员在用户管理里调整角色。这就是最小权限原则。

注册成功后不会直接登录，而是回到登录页并自动填好用户名，登录之后进入工作台。

## 四、配合画面（建议录屏动作，与念稿同步）

| 念到 | 画面操作 |
|---|---|
| 「登录页点立即注册」 | 登录页 → 点「立即注册」，表单展开（副标题「注册后将以只读成员身份加入平台」） |
| 「用户名 3 到 32 位…」 | 用户名框输入 `demo_viewer`，鼠标停在占位提示上 |
| 「密码至少 8 位…」 | 输入 `Demo12345`，再输入确认密码 |
| 「必须勾选安全规范」 | 先**不勾**点提交 → 出现红色错误「请先同意平台账号与数据安全规范」→ 再勾选（这一步很出彩，别剪掉） |
| 「写入一条注册审计」 | 提交 → 出现成功提示（可切到「管理 → 审计日志」展示 `REGISTER / 自助注册成功，默认角色 VIEWER`） |
| 「一律是只读成员…」 | 切到「管理 → 用户管理」，指一下该账号角色列是 **VIEWER**（只读） |
| 「回到登录页，用户名已填好」 | 自动回到登录页、用户名已被预填 → 输入密码登录 → 进入工作台 |

## 五、念法提示

- 「**只读成员**」四个字放慢、加重——这是本段的安全亮点。
- 数字读法：`3 到 32 位`读「三到三十二位」；`8 位`读「八位」。
- 术语：`VIEWER` 读「维尤尔（只读）」或直接读「只读角色」。
- 语速基准 4.3 字/秒；若成片只给 15 秒，用第二档，把「审计」和「最小权限」两句删掉即可。
