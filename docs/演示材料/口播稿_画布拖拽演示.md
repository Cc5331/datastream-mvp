# 口播稿 · 画布拖拽演示（CSV 输入 → Excel 输出）

> 事实依据（均已核对代码与界面，可放心念）：
> 控件库共 **31 个**控件，分「输入 11 / 转换 10 / 输出 10」三栏；
> **CSV 输入**参数＝文件路径（默认 `test-resources/data/sales.csv`，**3000 行 8 列**：sale_id、region、product_category、sales_person、amount、quantity、sale_date、channel）、分隔符 `,`、是否包含表头；
> **Excel 输出**参数＝输出路径（默认 `output\output.xlsx`）、分隔符、工作表名（默认 `Data`，多个输出写同一文件时可区分 sheet）；内部实现是 CSV→xlsx 转换；
> 参数面板按控件 paramSchema（JSON Schema）自动渲染，`path` 必填；
> 提交后后端把 DAG 翻译成 Flink SQL 提交 Flink 集群，**状态每 5 秒回写**（SUBMITTED → RUNNING → COMPLETED），结果落在 `output\` 目录。

## 三、标准版（约 58 秒 · 250 字 · 4.3 字/秒）★推荐

先看画布编排。从左侧控件库的「输入」分栏，把 CSV 输入拖到画布上；再切到「输出」分栏，拖一个 Excel 输出。

按住 CSV 输入右侧的端口，拖到 Excel 输出上，连线就建好了——这条线定义了数据的流向。

选中 CSV 输入，右侧参数面板按控件的 Schema 自动渲染：文件路径、分隔符、是否包含表头。默认就是 3000 行的销售数据，也可以点「预览数据」先看一眼。

选中 Excel 输出，填输出路径和工作表名，点应用参数。

然后点保存、再点提交运行。后端把这张图翻译成 Flink SQL 提交到集群，状态每 5 秒回写；几秒钟后变成 COMPLETED，output 目录下就拿到了一个 xlsx 文件。

## 四、详版（约 113 秒 · 486 字 · 4.3 字/秒）

这一页是平台的核心：可视化编排。

左边是控件库，一共 31 个控件，分三类——输入、转换、输出。输入类有 CSV、Excel、Parquet、MySQL、PostgreSQL、Oracle、Kafka、HDFS、JSON、XML，输出类同样覆盖这些目标；中间是转换类，比如字段拼接、过滤、去重、空值校验。

演示一个最小链路：从「输入」分栏把 CSV 输入拖到画布，再从「输出」分栏拖一个 Excel 输出。

然后连线：按住 CSV 输入节点右侧的端口，拖到 Excel 输出上，松手即完成。画布支持缩放、平移和网格对齐，节点位置会自动参与排版。

选中 CSV 输入，右侧参数面板出现了——它是按控件的 Schema 自动渲染的，不需要为每个控件写表单：文件路径、分隔符、是否包含表头。默认指向项目自带的销售数据，3000 行 8 列，可以点预览数据核对字段。

再选中 Excel 输出，填输出路径和工作表名。工作表名默认 Data，如果多个输出接到同一个 xlsx，就用工作表名区分 sheet。

点应用参数写回节点，然后保存、提交运行。注意提交前会做静态检查，节点、连线和必填参数有问题会直接拦住。

通过之后，后端把这张 DAG 翻译成 Flink SQL 提交到 Flink 集群，状态每 5 秒回写；几秒钟后变成 COMPLETED，output 目录下就得到了一个 xlsx 文件。

## 五、配合画面（照着这个顺序点，与念稿同步）

| 步骤 | 操作 | 画面要点 |
|---|---|---|
| 1 | 顶栏点「画布设计」 | 空画布 + 左侧控件库（输入/转换/输出三栏） |
| 2 | 「输入」分栏 → 拖 **CSV Input** 到画布 | 落点出现绿色输入节点（带图标与名称） |
| 3 | 切「输出」分栏 → 拖 **Excel Output** | 落点出现输出节点 |
| 4 | 按住 CSV 输入**右侧端口**拖到 Excel 输出 | 出现连线；可顺手演示「撤销 / 重做」 |
| 5 | 点选 CSV 输入 | 右侧参数配置：**文件路径 / 分隔符 / 包含表头**；可点「预览数据」看前几行 |
| 6 | 点选 Excel 输出 | 右侧参数：**输出路径 / 分隔符 / 工作表名**（默认 Data） |
| 7 | 点「应用参数」 | 参数写回节点（提交前也会自动应用，不必抢时间） |
| 8 | 顶部「保存」 | 提示「DAG 已保存 (ID: …)」，作业列表出现新作业（DRAFT） |
| 9 | 顶部「提交运行」 | 「提交前检查」通过 → 提交 Flink（若故意留错，正好展示拦截能力） |
| 10 | 回「作业管理」看状态 | SUBMITTED → RUNNING → **COMPLETED**（每 5 秒刷新） |
| 11 | 打开 `output\output.xlsx` | Excel 里 3000 行数据，与源 CSV 列一致 |

## 六、念法提示

- **CSV** 读「C-S-V」或「逗号分隔文件」；**xlsx** 读「x-l-s-x」，也可直接说「Excel 文件」。
- **Schema** 读「Schema」；若评委偏中文，改说「按控件的参数结构自动渲染表单」。
- **端口**是节点两侧的小圆点，念到「按住端口」时鼠标要有明显停顿，观众才看得清动作。
- 数字：`3000 行 8 列`读「三千行八列」。
- ⚠️ **面板标签实测**：CSV 输入显示中文「文件路径」，但 **Excel 输出目前显示英文 `Excel path` / `Delimiter`**（后端注册表里就是英文）。录制前我可以把 `excel_output`、`csv_output` 的参数标题改成中文「输出路径 / 分隔符」，同屏就统一了——1 处代码 + 重启后端即生效（内置控件已支持按 type upsert，历史数据自动更新）。
